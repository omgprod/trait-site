Politique de
confidentialité.

Mise à jour : 25 octobre 2026 · Version actuelle du jeu Trait.

♥
Pas de compte. Pas de publicité. Pas de collecte par le jeu.

Ta progression reste sur ton appareil.

1. Responsable du jeu

Le jeu Trait est publié par Babapp. Pour toute question au sujet de cette politique ou des données, écris à contact@babapp.fr.

2. Compte et données personnelles

Trait ne demande pas de créer un compte, ne contient pas de publicité et n’intègre pas d’outil d’analyse ou de suivi publicitaire. Le jeu n’envoie pas de données personnelles à l’éditeur.

3. Sauvegarde locale

Pour fonctionner, le jeu conserve sur l’appareil des données de progression : étoiles par niveau, achats débloqués et choix d’équipement. Elles ne sont pas transmises à Babapp. La désinstallation ou la réinitialisation de l’appareil peut les effacer.

4. Freemium et paiements

Les trois premiers niveaux sont gratuits. Le déblocage du jeu complet et les compagnons optionnels sont prévus comme achats intégrés ponctuels, sans abonnement. Le fournisseur de paiement n’est pas encore intégré dans la version actuelle : aucun paiement n’est traité par Trait aujourd’hui.

Si des paiements sont activés dans une version future, la politique sera mise à jour avant la publication. Apple pourra alors traiter les informations nécessaires à la transaction selon ses propres règles.

5. Enfants

Le jeu ne collecte pas de données personnelles et n’inclut ni chat, ni contenu publié par les joueurs.

6. Modifications

Cette page sera actualisée si les fonctionnalités ou les traitements de données changent. La date ci-dessus indique la dernière mise à jour.

7. Nous contacter

Pour toute demande sur la confidentialité, écris à contact@babapp.fr. Comme le jeu ne transmet pas les sauvegardes à l’éditeur, Babapp ne dispose pas d’une copie à consulter ou supprimer.

Visite de ce site

Ce site est hébergé par GitHub Pages. GitHub peut enregistrer l’adresse IP et des informations techniques de visite pour la sécurité et le fonctionnement de l’hébergement, selon sa propre politique de confidentialité. Le site Trait n’ajoute pas de mesure d’audience ni de publicité.
