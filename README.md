# Trait website

Public marketing, assistance and privacy pages for the Trait mobile game. The private game repository stays private; the public site repository contains only static website files.

- Website: https://omgprod.github.io/trait-site/
- Support: https://omgprod.github.io/trait-site/assistance/
- Privacy policy: https://omgprod.github.io/trait-site/confidentialite/

The game offers its first three levels for free. There is no account or advertising. One-time purchases are planned for the full game and optional companions; the payment provider is not enabled in the current version.
