# Trait website

Public marketing, assistance and privacy pages for the Trait mobile game. This repository contains only the static website; the game source remains private in `omgprod/trait`.

- Website: https://omgprod.github.io/trait-site/
- Support: https://omgprod.github.io/trait-site/assistance/
- Privacy policy: https://omgprod.github.io/trait-site/confidentialite/

The first three levels are free, with no account or ads. The full game and optional companions are one-time purchases without subscriptions. On iOS, transactions go through the App Store.
